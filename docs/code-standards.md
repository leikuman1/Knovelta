# 代码规范

这里仅收录在至少三个不同日期实际复发、且证据充分的经验。项目已有的存储、审批和安全约束继续以 [CLAUDE.md](../CLAUDE.md) 与 [开发规格](../MemoAgent_Development_Spec.md) 为准，不将它们伪装成三次复发后的晋升结果。

开发及 Review 时阅读本页，再按任务查看 [LESSONS.md](../LESSONS.md) 中的相关经验。

## 晋升规则

每条规范保留稳定编号、问题键、规则、原因、发生日期及证据。晋升由 `npm run lessons:promote -- L编号` 执行，要求至少三个不同的发生日期，并由执行者先人工核验这些日期属于同类问题的独立事件。

重复审阅、补跑测试、同日多个 commit、将旧事件写入新报告均不增加日期数。自动校验只证明格式、日期和引用可定位，不代替语义核验。
